# 🐾 Catify Wall - Premium Cat Furniture Landing Page

Nowoczesna i responsywna strona typu Landing Page stworzona dla marki oferującej luksusowe meble ścienne dla kotów. Projekt skupia się na estetyce, przejrzystości oraz funkcjonalnościach wspierających konwersję.

Strona udostępniona jest na GitHub Pages: https://jlbdnrczk.github.io/landing-page-cat-furniture

## ✨ Kluczowe Funkcjonalności

* **Hero Section z Karuzelą:** Dynamicznie zmieniające się hasła reklamowe z płynnymi animacjami wejścia.
* **Modularna Architektura CSS:** Kod podzielony na logiczne bloki (zmienne, komponenty, sekcje) dla łatwiejszego zarządzania.
* **Interaktywna Galeria Produktów:** Karty produktów z efektami najechania (hover) i płynnym skalowaniem.
* **Testimonials Slider:** Przewijana poziomo sekcja opinii klientów wykorzystująca nowoczesną funkcję *Scroll Snap*.
* **Customowe Detale:** Listy z autorskimi znacznikami w kształcie łapek (🐾) oraz zaokrąglone, "designerskie" narożniki zdjęć.

## 🛠️ Technologie i Narzędzia

* **HTML5:** Semantyczna struktura dokumentu.
* **CSS3:** Wykorzystanie zmiennych (`:root`), Flexboxa oraz Grid Layoutu.
* **JavaScript (Vanilla):** Autorski skrypt do obsługi karuzeli w sekcji Hero oraz integracja z Google Analytics 4 (GA4).

## 📂 Struktura Projektu

Projekt został zorganizowany zgodnie z profesjonalnymi standardami:

* `/src/assets/images/` – Wszystkie zasoby graficzne (PNG, JPG).
* `/src/css/` – Modularne pliki stylów (variables, base, components, sections, main).
* `/src/js/` – Skrypty JavaScript.
* `index.html` – Główny plik strony.
